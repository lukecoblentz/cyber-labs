# Cybersecurity Labs | Network Security, Forensics & Vulnerability Assessment

Practical security analysis and investigation exercises from **ISM 4323 — Information Security and Risk Management** at the **University of South Florida**.

This repository documents hands-on coursework involving network traffic inspection, vulnerability assessment, and incident response in **educational lab environments**. Each case study summarizes the scenario, tools, investigative approach, security findings, and lessons learned, with screenshots where available.

## Featured Lab Projects

| Project | Focus | Tools | Documentation |
|---|---|---|---|
| **Incident Response & Forensic Analysis** | Investigating suspicious transfers, compromised credentials, and attack timelines in a simulated scenario | Wireshark, Autopsy, Windows Event Logs | [View case study](incident-response.md) |
| **Network Traffic Analysis** | Inspecting network protocols, comparing plaintext and encrypted communications, and analyzing wireless traffic | Wireshark, Kali Linux | [View case study](packet-analysis.md) |
| **Vulnerability Assessment & Penetration Testing** | Host discovery, service enumeration, vulnerability assessment, and risk-based remediation | Nmap, Zenmap, Nessus, Kali Linux | [View case study](vulnerability-assessment.md) |

## Areas of Practice

- **Network analysis:** TCP/IP, ICMP, HTTP, FTP, SSH, packet capture inspection, and protocol troubleshooting.
- **Security investigations:** Correlating network and host artifacts, building incident timelines, and identifying indicators of compromise.
- **Vulnerability management:** Scanning hosts and services, interpreting findings, prioritizing risks, and recommending mitigations.
- **Documentation:** Turning lab observations into clear findings, evidence descriptions, and security recommendations.

## Context & Responsible Use

These are **coursework case studies in controlled training environments**, not claims of authorized testing against production networks. The screenshots illustrate specific lab observations and should be interpreted alongside the individual write-ups. Information from a course scenario is presented for educational purposes.
